# Frappe & ERPNext Warm-Up Exercise

## Overview
This repository contains my submission for the Frappe & ERPNext Warm-Up Exercise. The exercise involved setting up ERPNext locally, creating a custom DocType, and adding sample records.

## Operating System
- Windows 11
- Docker Desktop
- Frappe Framework and ERPNext running locally using Docker

## What I Created
I created a custom DocType named **Fest Event** with the following fields:

- Event Name
- Date
- Venue
- Capacity

I also added three sample event records to the DocType and verified them in the list view.

## Steps I Followed
1. Set up Docker Desktop on Windows 11.
2. Cloned the official Frappe Docker repository.
3. Started the local ERPNext environment using Docker Compose.
4. Completed the initial ERPNext setup wizard.
5. Created the `Fest Event` DocType with four fields.
6. Added three sample event records.
7. Captured screenshots of the ERPNext home screen and Fest Event list view.

## Challenges Faced
The most challenging part was getting the local ERPNext environment running and understanding the initial setup process. I checked the Docker containers and site creation logs to verify that the services were running correctly. This helped me understand the basic setup and troubleshooting process in Frappe and ERPNext.
